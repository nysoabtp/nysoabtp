🎨 Générateur d'icônes PWA

Créez les icônes pour votre application NYSOA BTP

📋 Instructions :

  1. Cliquez sur "Générer les icônes" pour créer les aperçus
  2. Vérifiez que les icônes s'affichent correctement
  3. Cliquez sur "Télécharger toutes les icônes" pour les enregistrer
  4. Déplacez les fichiers téléchargés dans le dossier icons/ de votre projet
